# Student Grade Calculator
A comprehensive python tool built to process multiple students' marks securely, calculate averages, predict grade performance with insights, and structure metrics neatly.

## What I Learned
1. **Conditional Logic:** Using `if/elif/else` structures for system grading logic boundaries.
2. **Lists Management:** Storing multi-dimensional structures securely inside collections.
3. **Loops Architecture:** Processing multiple inputs cleanly through custom controls.
4. **Error Handling:** Defending parameters safely against null values via `try-except` filters.
5. **Functions Structure:** Organizing logical codes blocks modularly for safe reuse.

## Features Added
* Fully processes batch student evaluations.
* Validates numbers strictly inside 0-100 ranges.
* Generates clear tabular results alongside overall class performance metrics.
* File exports automated data storage to external system logs directly.
